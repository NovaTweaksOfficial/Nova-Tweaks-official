## Fastest workflow

1. Screen-record 20–30 seconds of the app: login → switch Fortnite/Minecraft → apply a tweak → benchmark/FPS screen → Dev Console.
2. Open CapCut → New project → import the clip.
3. Use **Auto captions**, a big hook in the first 1 second, and 0.5–1s cuts.
4. Add an AI voiceover or record your own.
5. Export **1080×1920, 30fps**.
6. Post 1–2× per day with 3–5 hashtags.

## Claims to keep safe

- Say **"reversible"** and **"no core game files touched."**
- Do **not** claim anti-cheat bypass, guaranteed FPS, or ban protection.
- Add **"results vary by PC."**
- Show real UI and real toggles, not fake benchmarks.
